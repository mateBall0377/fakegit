# 🚀 Руководство по сборке и тестированию FakeGit

## 📋 Системные требования
- **Тестировано на**: Arch Linux 
- **На Windows не тестировалось** ⚠️
- **Сборка**: CMake
- **Зависимости**: OpenSSL, nlohmann/json

## 🔧 Шаги сборки

### 1. Подготовка зависимостей
```bash
# Загрузка сабмодулей (если используются)
git submodule update --init --recursive
```

### 2. Сборка проекта
```bash
# Создаем папку build и заходим в нее
mkdir build
cd build

# Запускаем CMake для сборки проекта
cmake ..

# Собираем проект
make

# Возвращаемся в корневую папку проекта
cd ..
```

### 3. Тестирование системы
```bash
# Создаем тестовую директорию
mkdir test_repo
cd test_repo

# Инициализируем репозиторий
../build/fakegit init

# Дальше другие тесты...
```

## 🎯 Быстрая команда для тестирования
```bash
git submodule update --init --recursive && \
mkdir build && cd build && cmake .. && make && cd .. && \
mkdir test_repo && cd test_repo && ../build/fakegit init
```

## 📝 Что должно работать после сборки
- ✅ Инициализация репозитория (`fakegit init`)
- ✅ Создание коммитов (`fakegit push "message"`)
- ✅ Просмотр истории (`fakegit log`) 
- ✅ Восстановление состояний (`fakegit pull <hash>`)

---

*После успешной инициализации можно приступать к тестированию основных функций системы контроля версий.*
